## Regenerating / 如何重新生成

```bash
npm run build
electron . --screenshot   # Generates pet-cat(.en).png and settings-panel(.en).png for both languages
```

> Note: the images use the project's real sprite assets; `settings-panel*.png` is a canvas
> recreation of the panel (DOM capture of transparent windows is limited by DWM compositing on
> Windows, and this repo environment cannot screenshot a real desktop). For more realistic images,
> run the app on your own machine and replace these files with manual screenshots.
>
> 说明：图片使用项目内的真实精灵图资源合成；`settings-panel*.png` 为 canvas 绘制的面板外观
> 复刻。如需更真实的配图，可在自己电脑上运行应用后手动截图替换。
