## Regenerating / 如何重新生成

> ⏳ These images were produced **before the Tauri migration**. The Electron build had a
> `--screenshot` self-drawing mode (see the `pre-tauri-0.4.0` git tag) that has **not** been ported to
> Tauri yet, so there is no current command to regenerate them.
>
> 这些配图是**迁移到 Tauri 之前**生成的。原 Electron 版有一个 `--screenshot` 自绘模式
> （见 git 标签 `pre-tauri-0.4.0`），尚未移植过来，因此目前没有可用的重新生成命令。

Two options until that is ported / 在那之前有两种办法：

- Check out the pre-migration build (`git checkout pre-tauri-0.4.0`) and regenerate them there /
  切到迁移前的版本（`git checkout pre-tauri-0.4.0`）在其中重新生成；
- Or run the app and replace these files with real screenshots /
  或直接在真实桌面上运行应用后手动截图覆盖同名文件。

> Note: the images use the project's real sprite assets; `settings-panel*.png` is a canvas
> recreation of the panel (DOM capture of transparent windows is limited by DWM compositing on
> Windows). For more realistic images, run the app on your own machine and replace these files.
>
> 说明：图片使用项目内的真实精灵图资源合成；`settings-panel*.png` 为 canvas 绘制的面板外观
> 复刻。如需更真实的配图，可在自己电脑上运行应用后手动截图替换。
